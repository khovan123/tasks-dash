NO MOCK DATA · PRODUCTION CONFIGURATION

Quản lý dự án bằng dữ liệu thật, từ hệ thống thật.

Tasks Dash sử dụng GitHub OAuth cho đăng nhập, GitHub App installation token cho automation, Google Drive OAuth cho tài liệu và Discord webhook đã mã hóa cho thông báo.

Xem repositoryXem cách triển khai
01

Backend thật

NestJS kết nối MongoDB bằng cấu hình bắt buộc. Thiếu secret hoặc database thì dịch vụ fail-fast.

02

GitHub App

Webhook được xác minh trên raw body, chống xử lý trùng và liên kết PR bằng project key.

03

OAuth workspace

Workspace lấy từ session cookie HttpOnly đã ký, không tin header do trình duyệt tự gửi.

04

Discord automation

Webhook được kiểm tra trước khi lưu, mã hóa AES-256-GCM và xử lý rate limit.

05

Google Drive

Refresh token được mã hóa; cây folder được đọc trực tiếp từ Drive API theo root folder của dự án.

06

Automation engine

Rule theo sự kiện hoặc cron, có execution lock và lịch sử kết quả trong MongoDB.

SECURITY BOUNDARY

Website này không hiển thị số liệu giả.

Dashboard production chỉ xuất hiện sau khi backend được triển khai và người dùng đăng nhập. GitHub Pages là trang giới thiệu tĩnh, không giả lập trạng thái kết nối hoặc KPI.

Triển khai production

Đọc docs/PRODUCTION_SETUP.md, cấu hình secrets trong secret manager của nền tảng hosting, deploy API/Web bằng Docker và đăng ký callback/webhook URL công khai.
